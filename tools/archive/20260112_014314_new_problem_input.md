# Текст на задачата
Реши $x^2 = 4$.

# Решение
## Стратегија
Квадратен корен.

## Чекор по чекор

**Чекор 1: Квадратен корен**
$x = \pm 2$

# Pedagogical Notes
1. **Основна идеја:** Квадратната равенка има две решенија.
2. **Совет од Олимпиец:** Провери ги двете можни решенија.
3. **Чести грешки:** Не заборавај негативното решение.
