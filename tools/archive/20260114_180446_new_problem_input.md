# Изразување на тежишните линии и симетралите на аглите преку страните

# Текст на задачата
Да се изразат преку страните $a, b$ и $c$ на триаголникот $ABC$:
а) неговите тежишни линии ($t_a, t_b, t_c$);
б) неговите симетрали на агли ($s_a, s_b, s_c$).

# 💡 Помош (Hints)
<details>
<summary>Кликни за мала помош</summary>

1. За тежишните линии: Што ќе се случи ако ја продолжиме тежишната линија $t_a$ за уште една нејзина должина? Размислете за фигурата што се формира со темињата на триаголникот и новата точка.

$$a^2 + d_2^2 = 2(b^2 + c^2)$$

2. За симетралите на аглите: Искористете ја теоремата за симетрала на агол за да го одредите односот на отсечките на кои симетралата ја дели спротивната страна.

$$BM : MC = c : b$$

3. Применете ја Косинусната теорема во двата помали триаголници формирани од симетралата.

</details>

# Решение
## 🧠 Експертска Анализа (Интуиција)
Драги олимпијци, оваа задача е темел на олимписката геометрија. Таа не бара само слепо користење формули, туку разбирање на **структурата** на триаголникот.

**Тригерот за дел (а):** Најодличниот начин за анализа на тежишна линија е нејзиното „дуплирање“. Ако ја продолжиме $t_a$ преку средината на страната $a$ до точка $D$, добиваме паралелограм $ABDC$. Зошто ова е паметно? Затоа што во паралелограмот важи идентитетот дека збирот на квадратите на дијагоналите е еднаков на збирот на квадратите на сите четири страни.

**Тригерот за дел (б):** Симетралата на аголот е попредизвикувачка. Клучот лежи во нејзиното својство да ја дели спротивната страна пропорционално на другите две страни. Ова ни овозможува да го примениме методот на „заеднички агол“ (преку Косинусната теорема) или помоќната Стјуартова теорема за да ја пресметаме нејзината должина.

## 📐 Детално Решение

<details>
<summary>Чекор 1: Изразување на тежишната линија t_a</summary>

Да ја најдеме тежишната линија $t_a$. Нека $D$ е точка таква што четириаголникот $ABDC$ е паралелограм. Во овој паралелограм:
- Страните се $b$ и $c$.
- Дијагоналите се страната $a$ и двојната тежишна линија $2t_a$.

Според теоремата за дијагонали на паралелограм:

$$a^2 + (2t_a)^2 = 2(b^2 + c^2)$$

$$4t_a^2 = 2b^2 + 2c^2 - a^2$$

Оттука ја добиваме формулата за тежишната линија:

$$t_a = \frac{1}{2}\sqrt{2b^2 + 2c^2 - a^2}$$

Аналогно се добиваат и останатите две тежишни линии $t_b$ и $t_c$.

</details>

<details>
<summary>Чекор 2: Подготовка за симетралата на аголот s_a</summary>

Нека симетралата на аголот $\alpha$ ја сече страната $a$ во точка $M$. Според теоремата за симетрала на агол, важи:

$$BM : MC = c : b$$

Бидејќи $BM + MC = a$, можеме да ги изразиме овие отсечки преку страните:

$$BM = \frac{ac}{b+c}, \quad MC = \frac{ab}{b+c}$$

</details>

<details>
<summary>Чекор 3: Изразување на симетралата s_a</summary>

Нека $\angle AMC = \phi$. Тогаш $\angle AMB = 180^\circ - \phi$. Применуваме Косинусна теорема на $\triangle ACM$ и $\triangle ABM$:

$$b^2 = s_a^2 + MC^2 - 2s_a MC \cos \phi$$

$$c^2 = s_a^2 + BM^2 + 2s_a BM \cos (180^\circ - \phi) = s_a^2 + BM^2 + 2s_a BM \cos \phi$$

Ако првата равенка ја помножиме со $BM$, а втората со $MC$ и ги собереме, членот со $\cos \phi$ ќе се поништи:

$$b^2 BM + c^2 MC = s_a^2(BM + MC) + BM \cdot MC (BM + MC)$$

Заменувајќи ги вредностите за $BM$ и $MC$ и средувајќи го изразот, добиваме:

$$s_a^2 = \frac{bc}{(b+c)^2} \left[ (b+c)^2 - a^2 \right]$$

Од ова следува конечната форма:

$$s_a = \frac{\sqrt{bc((b+c)^2 - a^2)}}{b+c}$$

Забелешка: Ова често се запишува и преку полупериметарот $s$: $s_a = \frac{2\sqrt{bcs(s-a)}}{b+c}$.

</details>

**Краен одговор:** 
а) $t_a = \frac{1}{2}\sqrt{2b^2 + 2c^2 - a^2}$, $t_b = \frac{1}{2}\sqrt{2a^2 + 2c^2 - b^2}$, $t_c = \frac{1}{2}\sqrt{2a^2 + 2b^2 - c^2}$
б) $s_a = \frac{\sqrt{bc((b+c)^2 - a^2)}}{b+c}$ (аналогно за $s_b$ и $s_c$)

## 👨‍🏫 Менторски Белешки
1.  **Златен Совет:** Конструкцијата на паралелограм преку тежишната линија е една од најкорисните алатки во олимписката геометрија. Таа го претвора проблемот на триаголник во проблем на симетрија.
2.  **Чести Грешки:** При изведување на симетралата, учениците често ги заменуваат $b$ и $c$ во односот $BM/MC$. Запомнете: отсечката до темето $B$ е пропорционална на страната $c$ (бидејќи таа страна излегува од $B$).
3.  **Зошто ова е важно:** Овие формули не се само за меморирање. Нивното изведување е вежба за алгебарска манипулација во геометријата, што е клучно за решавање на потешки задачи на BMO и IMO.

### 🔗 Поврзани вештини
* **Примарна вештина:** Метрички зависности во триаголник
* **Потребни предзнаења:** Косинусна теорема, Теорема за симетрала на агол, Стјуартова теорема.

```python
from manim import *

class SolutionScene(Scene):
    def construct(self):
        self.camera.background_color = WHITE
        
        # Define vertices of triangle ABC
        A = UP * 2 + LEFT * 0.5
        B = DOWN * 1 + LEFT * 2.5
        C = DOWN * 1 + RIGHT * 2
        
        # Triangle
        triangle = Polygon(A, B, C, color=BLACK, stroke_width=4)
        
        # Median t_a
        M_a = (B + C) / 2
        median = Line(A, M_a, color=BLUE, stroke_width=3)
        
        # Parallelogram point D (reflect A over M_a)
        D = 2 * M_a - A
        para_lines = VGroup(
            Line(B, D, color=GRAY, stroke_dash_array=),
            Line(C, D, color=GRAY, stroke_dash_array=),
            Line(M_a, D, color=BLUE, stroke_dash_array=)
        )
        
        # Bisector s_a
        # Angle bisector point M on BC
        # Using vector math to find M
        vec_ab = B - A
        vec_ac = C - A
        unit_ab = vec_ab / np.linalg.norm(vec_ab)
        unit_ac = vec_ac / np.linalg.norm(vec_ac)
        bisector_dir = unit_ab + unit_ac
        # Intersection of line A + k*bisector_dir and BC
        # Result of calculation (visual approximation for code)
        M_pos = A + 2.8 * (bisector_dir / np.linalg.norm(bisector_dir))
        bisector = Line(A, M_pos, color=RED, stroke_width=3)

        # Labels - English/Math only as per rules
        lbl_A = MathTex("A", color=BLACK).next_to(A, UP)
        lbl_B = MathTex("B", color=BLACK).next_to(B, LEFT)
        lbl_C = MathTex("C", color=BLACK).next_to(C, RIGHT)
        lbl_D = MathTex("D", color=BLACK).next_to(D, DOWN)
        lbl_ta = MathTex("t_a", color=BLUE).next_to(median.get_center(), LEFT, buff=0.1)
        lbl_sa = MathTex("s_a", color=RED).next_to(bisector.get_center(), RIGHT, buff=0.1)
        
        # Add to scene
        self.add(triangle, median, para_lines, bisector, lbl_A, lbl_B, lbl_C, lbl_D, lbl_ta, lbl_sa)
```
