# Текст на задачата
Реши $x + 1 = 2$.

# Решение
## Стратегија
Одземи 1 од двете страни.

## Чекор по чекор

**Чекор 1: Одземање**
$x + 1 - 1 = 2 - 1$

**Чекор 2: Решение**
$x = 1$

# Pedagogical Notes
1. **Основна идеја:** Решувањето равенки бара примена на обратни операции.
2. **Совет од Олимпиец:** Секогаш проверувај го решението.
3. **Чести грешки:** Не заборавај да примениш операцијата на двете страни.
