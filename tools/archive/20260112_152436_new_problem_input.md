# Равенки со бесконечно многу решенија и целобројни параметри

# Текст на задачата
Определи ги целобројните параметри $a, b$ и $c$ такви што равенката:

$$(x - a)(x - 6) + 3 = (x + b)(x + c)$$

има бесконечно многу реални решенија.

# 💡 Помош (Hints)
<details>
<summary>Кликни за мала помош</summary>

1. Кога една алгебарска равенка има бесконечно многу решенија, тоа значи дека таа е всушност идентитет — важи за секоја вредност на $x$.

2. Наместо да ги множите заградите веднаш, размислете која вредност на $x$ би елиминирала голем дел од изразот. Што се случува ако $x = 6$?

3. Бидејќи $b$ и $c$ се цели броеви, нивните комбинации со 6 исто така мора да бидат цели броеви кои го делат бројот 3.

</details>

# Решение
## 🧠 Експертска Анализа (Интуиција)
Клучот за оваа задача лежи во разбирањето на природата на равенките. Ако една квадратна равенка (или равенка од кој било степен) има повеќе решенија отколку што е нејзиниот степен, таа мора да биде **идентитет**. Ова е моќен **тригер**: ако тврдењето важи за „бесконечно многу $x$“, тогаш важи за **секој** $x$.

**Зошто да не множиме веднаш?** Бруталната сила (експандирање на двете страни) би нè довела до систем равенки каде што треба да ги изедначиме коефициентите пред $x^2, x^1$ и слободниот член. Но, олимпискиот пристап бара елеганција. Паметната супституција е побрза. Ако избереме $x = 6$, левата страна на равенката драстично се поедноставува, оставајќи ни само константа. Ова веднаш го трансформира проблемот од алгебарски во теоретско-броен: наоѓање на целобројни делители на бројот 3.

Откако ќе ги најдеме можните вредности за $b$ и $c$, параметарот $a$ ќе го одредиме со споредување на линеарните членови или слободните членови на двете полиномни страни.

## 📐 Детално Решение

<details>
<summary>Чекор 1: Примена на својството за идентитет</summary>

Бидејќи равенката има бесконечно многу решенија, таа важи за сите реални броеви $x$. Затоа, таа мора да важи и за специфичната вредност $x = 6$. Заменувајќи $x = 6$ во равенката добиваме:

$$(6 - a)(6 - 6) + 3 = (6 + b)(6 + c)$$

$$0 + 3 = (6 + b)(6 + c)$$

$$3 = (6 + b)(6 + c)$$

Бидејќи $b$ и $c$ се цели броеви, изразите $(6 + b)$ и $(6 + c)$ се исто така цели броеви кои се делители на 3.

</details>

<details>
<summary>Чекор 2: Разгледување на целобројни делители</summary>

Бројот 3 може да се запише како производ на два цели броја во точно 4 случаи:

1.  $6 + b = 1, 6 + c = 3$
2.  $6 + b = 3, 6 + c = 1$
3.  $6 + b = -1, 6 + c = -3$
4.  $6 + b = -3, 6 + c = -1$

Да ги анализираме овие случаи за да ги најдеме $a, b$ и $c$.

</details>

<details>
<summary>Чекор 3: Анализа на случаите 1 и 2 (Позитивни делители)</summary>

**Случај 1:** Ако $6 + b = 1$ и $6 + c = 3$, тогаш $b = -5$ и $c = -3$.
Равенката станува:

$$(x - a)(x - 6) + 3 = (x - 5)(x - 3)$$

Го развиваме десниот дел: $(x - 5)(x - 3) = x^2 - 8x + 15$.
Го развиваме левиот дел: $x^2 - (a + 6)x + 6a + 3$.
Со изедначување на коефициентите пред $x$:

$$a + 6 = 8 \implies a = 2$$

Проверка за слободниот член: $6(2) + 3 = 12 + 3 = 15$, што се совпаѓа.
Решение: $(a, b, c) = (2, -5, -3)$.

**Случај 2:** Ако $6 + b = 3$ и $6 + c = 1$, тогаш $b = -3$ и $c = -5$.
Повторувајќи ја истата постапка, добиваме $a = 2$.
Решение: $(a, b, c) = (2, -3, -5)$.

</details>

<details>
<summary>Чекор 4: Анализа на случаите 3 и 4 (Негативни делители)</summary>

**Случај 3:** Ако $6 + b = -1$ и $6 + c = -3$, тогаш $b = -7$ и $c = -9$.
Равенката станува:

$$(x - a)(x - 6) + 3 = (x - 7)(x - 9)$$

Десната страна е: $x^2 - 16x + 63$.
Изедначувајќи го коефициентот пред $x$ со левата страна ($a + 6$):

$$a + 6 = 16 \implies a = 10$$

Проверка за слободниот член: $6(10) + 3 = 60 + 3 = 63$. (Точно).
Решение: $(a, b, c) = (10, -7, -9)$.

**Случај 4:** Ако $6 + b = -3$ и $6 + c = -1$, тогаш $b = -9$ и $c = -7$.
Слично, добиваме $a = 10$.
Решение: $(a, b, c) = (10, -9, -7)$.

</details>

**Краен одговор:** Параметрите $(a, b, c)$ може да бидат:
$\boxed{(2, -5, -3), (2, -3, -5), (10, -7, -9), (10, -9, -7)}$

## 👨‍🏫 Менторски Белешки
1.  **Златен Совет:** Кога равенката е во облик на полиноми, бесконечно многу решенија значат дека полиномите од левата и десната страна се идентични. Наместо да решавате за $x$, вие ги решавате вредностите на параметрите.
2.  **Чести Грешки:** Учениците често забораваат на негативните делители на 3 (т.е. $-1$ и $-3$). Ова доведува до губење на точно половина од решенијата.
3.  **Зошто ова е важно:** Овој концепт е основа за разбирање на методот на неопределени коефициенти, кој е клучен во напредната алгебра и анализа.

### 🔗 Поврзани вештини
* **Примарна вештина:** Алгебарски идентитети (Macedonian: Алгебарски идентитети)
* **Потребни предзнаења:** Својства на полиноми, теорија на делители во $\mathbb{Z}$.

from manim import *

class SolutionScene(Scene):
    def construct(self):
        self.camera.background_color = WHITE
        
        # Display the main equation
        eq = MathTex(
            r"(x - a)(x - 6) + 3 = (x + b)(x + c)", 
            color=BLACK
        ).to_edge(UP)
        
        # Subtitle - Infinitely many solutions
        subtitle = Text(
            "Condition: Identity for all x", 
            color=BLUE, 
            font_size=24
        ).next_to(eq, DOWN)
        
        # Step: x = 6
        step1 = MathTex(
            r"\text{Let } x = 6 \implies 3 = (6 + b)(6 + c)", 
            color=BLACK
        ).shift(UP * 0.5)
        
        # Division into cases
        cases = VGroup(
            MathTex(r"1) \ a=2, b=-5, c=-3", color=BLACK),
            MathTex(r"2) \ a=2, b=-3, c=-5", color=BLACK),
            MathTex(r"3) \ a=10, b=-7, c=-9", color=BLACK),
            MathTex(r"4) \ a=10, b=-9, c=-7", color=BLACK)
        ).arrange(DOWN, aligned_edge=LEFT, buff=0.3).next_to(step1, DOWN, buff=0.5)
        
        # Highlight final answer
        box = SurroundingRectangle(cases, color=RED, buff=0.2)
        
        self.add(eq, subtitle, step1, cases, box)
