# Цел дел од збир со кубни корени

# Текст на задачата
Со $[x]$ го означуваме најголемиот цел број помал или еднаков на $x$. Определи ја вредноста на изразот:

$$\left[ \frac{1}{\sqrt{1^2}} + \frac{1}{\sqrt{2^2}} + \dots + \frac{1}{\sqrt{1000^2}} \right]$$

# 💡 Помош (Hints)
<details>
<summary>Кликни за мала помош</summary>

1. Директно пресметување на овој збир е невозможно без компјутер. Наместо тоа, обидете се да ја ограничите секоја поединечна вредност $\frac{1}{\sqrt{n^2}}$ помеѓу два изрази кои можат да се сумираат телескопски.

2. Размислете за изводот на функцијата $f(x) = 3x^{1/3}$. Како тој се однесува во споредба со општиот член $\frac{1}{n^{2/3}}$?

$$f(n+1) - f(n) \approx f'(n) = \frac{1}{n^{2/3}}$$

3. Користете ги неравенствата $3(\sqrt{n+1} - \sqrt{n}) < \frac{1}{\sqrt{n^2}}$ и $\frac{1}{\sqrt{n^2}} < 3(\sqrt{n} - \sqrt{n-1})$.

</details>

# Решение
## 🧠 Експертска Анализа (Интуиција)
Кога ќе видиме збир на реципрочни вредности на корени со висок индекс (како 1000), нашиот **тригер** треба да биде **проценка преку интеграли** или **телескопско сумирање**. Збирот претставува десна или лева Риманова сума за функцијата $f(x) = x^{-2/3}$.

**Зошто не можеме да користиме брутална сила?** Секој член е ирационален број, а нивното собирање без прецизни граници ќе доведе до огромна грешка. Нашата цел е да го „заглавиме“ збирот $S$ помеѓу два последователни цели броја, на пример $k < S < k+1$. Тогаш ќе знаеме дека $[S] = k$.

Клучниот увид лежи во идентитетот на средна вредност или Лагранжовата теорема. За функцијата $g(x) = 3x^{1/3}$, нејзиниот извод е $g'(x) = x^{-2/3}$. Ова значи дека разликата $3(\sqrt{n+1} - \sqrt{n})$ е многу блиску до $\frac{1}{\sqrt{n^2}}$. Бидејќи изводот опаѓа, разликата на десната страна ќе биде помала од вредноста на левиот крај и поголема од вредноста на десниот крај на интервалот $[n, n+1]$. Ова ни ги дава совршените алатки за „телескопирање“ на целиот збир.

## 📐 Детално Решение

<details>
<summary>Чекор 1: Изведување на основните неравенства</summary>

Користиме својство на функцијата $f(x) = 3x^{1/3}$. Според Лагранжовата теорема за средна вредност на интервалот $[n, n+1]$, постои $c \in (n, n+1)$ така што:

$$3\sqrt{n+1} - 3\sqrt{n} = \frac{3 \cdot \frac{1}{3}}{c^{2/3}}(n+1 - n) = \frac{1}{\sqrt{c^2}}$$

Бидејќи функцијата $1/\sqrt{x^2}$ е строго опаѓачка на $(0, \infty)$, за $n < c < n+1$ важи:

$$\frac{1}{\sqrt{(n+1)^2}} < 3(\sqrt{n+1} - \sqrt{n}) < \frac{1}{\sqrt{n^2}}$$

Од десната страна на ова двојно неравенство ја добиваме долната граница за нашиот член:
$$3(\sqrt{n+1} - \sqrt{n}) < \frac{1}{\sqrt{n^2}}$$

Слично, разгледувајќи го интервалот $[n-1, n]$, ја добиваме горната граница:
$$\frac{1}{\sqrt{n^2}} < 3(\sqrt{n} - \sqrt{n-1})$$

</details>

<details>
<summary>Чекор 2: Сумирање за долната граница</summary>

Нека $S = \sum_{n=1}^{1000} \frac{1}{\sqrt{n^2}}$. Користејќи го левото неравенство од Чекор 1 за сите $n$ од 1 до 1000:

$$S > \sum_{n=1}^{1000} 3(\sqrt{n+1} - \sqrt{n})$$

Ова е телескопски збир:
$$S > 3(\sqrt{2} - \sqrt{1} + \sqrt{3} - \sqrt{2} + \dots + \sqrt{1001} - \sqrt{1000})$$
$$S > 3(\sqrt{1001} - \sqrt{1})$$
$$S > 3(\sqrt{1001} - 1)$$

Бидејќи $\sqrt{1001} > \sqrt{1000} = 10$, имаме:
$$S > 3(10 - 1) = 27$$

</details>

<details>
<summary>Чекор 3: Сумирање за горната граница</summary>

За горната граница, го користиме десното неравенство од Чекор 1, но за $n \ge 2$, додека првиот член го оставаме како 1:

$$S = 1 + \sum_{n=2}^{1000} \frac{1}{\sqrt{n^2}} < 1 + \sum_{n=2}^{1000} 3(\sqrt{n} - \sqrt{n-1})$$

Повторно имаме телескопски збир:
$$S < 1 + 3(\sqrt{2} - \sqrt{1} + \sqrt{3} - \sqrt{2} + \dots + \sqrt{1000} - \sqrt{999})$$
$$S < 1 + 3(10 - 1)$$
$$S < 1 + 27 = 28$$

</details>

<details>
<summary>Чекор 4: Финализирање на резултатот</summary>

Од Чекор 2 и Чекор 3 добиваме:
$$27 < S < 28$$

Според дефиницијата за цел дел, најголемиот цел број кој не е поголем од $S$ мора да биде 27.

</details>

**Краен одговор:** $\boxed{27}$

## 👨‍🏫 Менторски Белешки
1.  **Златен Совет:** Телескопското сумирање преку изводи е „швајцарски нож“ за вакви задачи. Ако имате збир од типот $\sum f(n)$, побарајте функција $g$ таква што $g' = f$. Тогаш збирот е приближно $g(N) - g(1)$.
2.  **Чести Грешки:** Најчеста грешка е директно сумирање на десното неравенство од $n=1$. Тогаш ќе добиете $3(\sqrt{1} - \sqrt{0})$, што работи, но често пати во слични задачи членот во нула е недефиниран. Секогаш е побезбедно да се изолира првиот член за да се добие попрецизна горна граница.
3.  **Зошто ова е важно:** Овој метод е дискретна верзија на интегралниот тест за конвергенција на редови. Тоа е основата на напредната математичка анализа.

from manim import *

class SolutionScene(Scene):
    def construct(self):
        self.camera.background_color = WHITE
        
        # --- CONFIGURATION ---
        axes = Axes(
          x_range=[1, 10, 1],
          y_range=[0, 1.5, 0.5],
          axis_config={"color": BLACK, "stroke_width": 2},
          tips=False
        ).scale(0.8)
        
        # Function f(x) = 1/x^(2/3)
        graph = axes.plot(lambda x: x**(-2/3), x_range=[0.5, 10], color=BLACK)
        
        # Riemann Sum Bars (illustrative for n=1 to 10)
        bars = VGroup()
        for i in range(1, 10):
            x0 = i
            y0 = 0
            x1 = i + 1
            y1 = x0 ** (-2/3)
            # The bar's width is the difference in x, height is f(x0)
            bar = Rectangle(
                width=axes.c2p(x1, 0)[0] - axes.c2p(x0, 0)[0],
                height=axes.c2p(x0, y1)[1] - axes.c2p(x0, 0)[1],
                fill_opacity=0.3,
                fill_color=BLUE,
                stroke_color=BLACK,
                stroke_width=1
            )
            # Place bar so its lower left corner is at (x0, 0)
            bar.move_to(axes.c2p(x0, y1/2), aligned_edge=LEFT)
            bars.add(bar)
            
        # Labels (centered in a row above axes)
        lbl_f = MathTex(r"f(n) = \frac{1}{\sqrt{n^2}}", color=BLACK)
        lbl_sum = MathTex(r"S = \sum_{n=1}^{1000} f(n)", color=BLACK)
        label_row = VGroup(lbl_f, lbl_sum).arrange(RIGHT, buff=1.2).next_to(axes, UP, buff=0.5).move_to(axes.get_center() + UP*2.2)

        # Bounding Text (in a single row, centered just below axes)
        bounds = MathTex(r"27 < S < 28", color=RED).scale(1.2)
        result = MathTex(r"[S] = 27", color=BLACK).scale(1.2)
        bottom_row = VGroup(bounds, result).arrange(RIGHT, buff=1.2)
        bottom_row.next_to(axes, DOWN, buff=0.5)
        bottom_row.move_to(axes.get_center() + DOWN*1.5)

        self.add(axes, graph, bars, label_row, bottom_row)
