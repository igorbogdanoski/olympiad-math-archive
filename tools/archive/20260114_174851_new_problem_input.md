# Однос на катети кај правоаголен триаголник преку висина и тежишна линија

# Текст на задачата
Од темето $C$ на правоаголниот триаголник $ABC$ (со прав агол во темето $C$) се повлечени висината и тежишната линија чиј однос е $12:13$. Одреди го односот од катетите во тој триаголник.

# 💡 Помош (Hints)
<details>
<summary>Кликни за мала помош</summary>

1. Кое е најважното својство на тежишната линија кон хипотенузата во правоаголен триаголник? Како таа се однесува во однос на самата хипотенуза?

$$t_c = \frac{c}{2}$$

2. Нека висината е $h_c = 12k$ и тежишната линија е $t_c = 13k$. Набљудувај го малиот правоаголен триаголник формиран од висината, тежишната линија и дел од хипотенузата. Можеш ли да ја најдеш должината на тој дел?

3. Откако ќе ги знаеш проекциите на катетите врз хипотенузата, искористи ја Питагоровата теорема за да ги изразиш квадратите на катетите $a^2$ и $b^2$ преку параметарот $k$.

</details>

# Решение
## 🧠 Експертска Анализа (Интуиција)
Оваа задача нè повикува да ја истражиме внатрешната геометрија на правоаголниот триаголник. **Клучниот тригер** овде е односот $12:13$. Секој искусен натпреварувач веднаш ја препознава Питагоровата тројка $(5, 12, 13)$. Ова ни сугерира дека растојанието меѓу подножјето на висината и средината на хипотенузата ќе биде пропорционално на 5.

**Детективска работа:** Зошто ова е важно? Тежишната линија во правоаголен триаголник го дели триаголникот на два рамнокраки триаголници бидејќи нејзината должина е еднаква на половина од хипотенузата. Подножјето на висината, пак, ни овозможува да го примениме Питагоровото правило во помали триаголници. Нашата стратегија е едноставна: да ги „парчеиме“ должините на хипотенузата почнувајќи од нејзината средина, а потоа да ги искористиме тие парчиња за да стигнеме до катетите.

## 📐 Детално Решение

<details>
<summary>Чекор 1: Поставување на основните величини</summary>

Нека $h_c$ е висината спуштена од темето $C$ кон хипотенузата $AB$, а $t_c$ е тежишната линија од истото теме. Од условот на задачата имаме:

$$h_c : t_c = 12 : 13$$

Можеме да запишеме $h_c = 12k$ и $t_c = 13k$ за некој позитивен реален број $k$. Нека $D$ е средината на хипотенузата $AB$ (каде завршува тежишната линија), а $E$ е подножјето на висината спуштена од $C$.

Познато е дека во правоаголен триаголник тежишната линија кон хипотенузата е еднаква на половина од хипотенузата:

$$CD = t_c = 13k \implies AD = BD = 13k$$

Оттука, целата хипотенуза $c = AB = 2t_c = 26k$.

</details>

<details>
<summary>Чекор 2: Пресметување на делот DE на хипотенузата</summary>

Набљудуваме го правоаголниот триаголник $CDE$, каде $\angle CED = 90^\circ$. Во него хипотенуза е $CD = 13k$, а едната катета е висината $CE = h_c = 12k$. Со примена на Питагоровата теорема за триаголникот $CDE$:

$$DE = \sqrt{CD^2 - CE^2} = \sqrt{(13k)^2 - (12k)^2}$$

$$DE = \sqrt{169k^2 - 144k^2} = \sqrt{25k^2} = 5k$$

</details>

<details>
<summary>Чекор 3: Определување на проекциите на катетите</summary>

Сега можеме да ги најдеме должините на отсечките $AE$ и $BE$ на кои висината ја дели хипотенузата.

За $BE$ (да претпоставиме дека $E$ е поблиску до $B$):
$$BE = BD - DE = 13k - 5k = 8k$$

За $AE$:
$$AE = AD + DE = 13k + 5k = 18k$$

</details>

<details>
<summary>Чекор 4: Наоѓање на односот на катетите</summary>

Сега ја применуваме Питагоровата теорема во правоаголните триаголници $BCE$ и $ACE$:

За катетата $a = BC$:
$$a^2 = CE^2 + BE^2 = (12k)^2 + (8k)^2 = 144k^2 + 64k^2 = 208k^2$$

За катетата $b = AC$:
$$b^2 = CE^2 + AE^2 = (12k)^2 + (18k)^2 = 144k^2 + 324k^2 = 468k^2$$

Го пресметуваме односот на квадратите на катетите:

$$\frac{a^2}{b^2} = \frac{208k^2}{468k^2} = \frac{208}{468}$$

Скратуваме со 4:
$$\frac{a^2}{b^2} = \frac{52}{117}$$

Скратуваме со 13:
$$\frac{a^2}{b^2} = \frac{4}{9}$$

Оттука, односот на катетите е:
$$\frac{a}{b} = \sqrt{\frac{4}{9}} = \frac{2}{3}$$

</details>

**Краен одговор:** Односот на катетите во триаголникот е $\boxed{2:3}$.

## 👨‍🏫 Менторски Белешки
1.  **Златен Совет:** Кај задачи со правоаголен триаголник, секогаш имајте ги на ум Питагоровите тројки $(3, 4, 5)$, $(5, 12, 13)$, $(8, 15, 17)$. Тие често го откриваат патот до решението пред воопшто да почнете со формалното пишување.
2.  **Чести Грешки:** Внимавајте при изборот на ознаките. Понекогаш учениците забораваат дека $t_c$ завршува во средината на хипотенузата, па погрешно ги пресметуваат отсечките $AE$ и $BE$. Секогаш цртајте прецизна скица!
3.  **Зошто ова е важно:** Оваа задача ја вежба способноста за манипулација со пропорционални величини и нивно поврзување преку заеднички елемент (во овој случај висината $h_c$).

from manim import *

class SolutionScene(Scene):
    def construct(self):
        self.camera.background_color = WHITE
        
        # Define vertices based on the ratio a:b = 2:3
        # If a=2, b=3, then hypotenuse c = sqrt(13)
        # Let's scale for visibility
        scale = 1.5
        C = ORIGIN
        A = UP * 3 * scale
        B = RIGHT * 2 * scale
        
        # Triangle and lines
        triangle = Polygon(A, B, C, color=BLACK, stroke_width=4)
        
        # Hypotenuse AB
        hypotenuse = Line(A, B, color=BLACK)
        
        # Midpoint D
        D = hypotenuse.get_center()
        median = Line(C, D, color=RED, stroke_width=3)
        
        # Altitude point E
        # Slope of AB is -3/2. Perpendicular from C has slope 2/3.
        # Intersection of y = (2/3)x and y - 3 = (-3/2)x -> (2/3)x - 3 = -1.5x -> 2.166x = 3 -> x=1.38
        E = hypotenuse.get_projection(C)
        altitude = Line(C, E, color=BLUE, stroke_width=3)
        
        # Labels (English/Math only)
        lbl_A = MathTex("A", color=BLACK).next_to(A, UP)
        lbl_B = MathTex("B", color=BLACK).next_to(B, RIGHT)
        lbl_C = MathTex("C", color=BLACK).next_to(C, DOWN + LEFT, buff=0.1)
        lbl_D = MathTex("D", color=BLACK).next_to(D, UP + RIGHT, buff=0.1)
        lbl_E = MathTex("E", color=BLACK).next_to(E, UP + RIGHT, buff=0.1)
        
        # Group objects
        geom = VGroup(triangle, median, altitude, lbl_A, lbl_B, lbl_C, lbl_D, lbl_E)
        
        # Information Text
        info = VGroup(
            MathTex("h_c : t_c = 12 : 13", color=BLACK),
            MathTex("CD = t_c = 13k", color=RED),
            MathTex("CE = h_c = 12k", color=BLUE),
            MathTex("DE = 5k", color=BLACK)
        ).arrange(DOWN, aligned_edge=LEFT).to_corner(UL)
        
        # Final Result
        result = MathTex("a : b = 2 : 3", color=BLACK).scale(1.2).to_corner(DL)
        box = SurroundingRectangle(result, color=BLACK, buff=0.2)
        
        # Render
        self.add(geom, info, result, box)
