## ПРАВИЛА ЗА ДОКАЗОТ:

### 1. ИЗБОР НА МЕТОД:
- Геометриски теореми: Доказ со плоштини, слични триаголници, координати, вектори
- Алгебарски теореми: Доказ со манипулација на равенки, индукција, контрадикција
- Комбинаторни теореми: Доказ со броење, биекција, рекурзија
- Аналитички теореми: Доказ со граници, деривации, интеграли

### 2. НИВО НА ДЕТАЛИ:
- Basic: Елементарен доказ, основни концепти
- Intermediate: Стандарден олимписки доказ, средно ниво
- Advanced: Напреден/елегантен доказ, универзитетско ниво

### 3. СТРУКТУРА:
- Максимум 5 чекори (за да биде разбирлив)
- Секој чекор треба да има текст + формула
- Користи LaTeX за математички изрази
- Објасни секој симбол и концепт

### 4. ВАЛИДАЦИЈА:
- Доказот мора да биде математички точен
- Сите претпоставки треба да се наведат
- Заклучокот треба да следи логично
- Избегни круг во доказувањето

### 5. ПЕДАГОШКИ ЕЛЕМЕНТИ:
- Додај интуитивни објаснувања
- Спомни алтернативни пристапи ако постојат
- Поврзи со поврзани концепти

ТЕОРЕМАТА МОРДА ДА СЕ ДОКАЖЕ: [ИМЕ НА ТЕОРЕМАТА]

ГЕНЕРИРАЈ САМО ДОКАЗОТ ВО ГОРЕНАВЕДЕНИОТ ФОРМАТ!
```

### 3. ЗАМЕНИ ПЛАСХОЛДЕРИ
- **[ИМЕ НА ТЕОРЕМАТА]**: Полно име (пр. "Pythagorean Theorem")
- **[КАТЕГОРИЈА]**: Geometry, Algebra, Number Theory, итн.
- **[ТЕЖИНА]**: Basic, Intermediate, Advanced

### 4. ДОБИЈ ДОКАЗ ОД AI
AI ќе генерира доказ во овој формат:
```
## 📝 Доказ (Преку координати)
Овој доказ користи координатен систем за едноставност.

### Чекор 1: Поставување координати
Поставуваме правоаголен триаголник со темења во (0,0), (a,0), (0,b).

### Чекор 2: Пресметка на страни
Должината на хипотенузата: √(a² + b²)

[... други чекори ...]

### Заклучок:
Добиваме a² + b² = c², што требаше да се докаже.
```

### 5. ДОДАЈ LATEX ФОРМУЛИ
Додадете LaTeX формули во $$ за математички изрази:

```
### Чекор 1: Поставување координати
$$ a^2 + b^2 = c^2 $$
```

## ПРАВИЛА ЗА MANIM ВИЗУЕЛИЗАЦИИ

### 1. КОГА ДА ГЕНЕРИРАШ MANIM КОД:
- За геометриски теореми (триаголници, кружници, вектори)
- Кога доказот има визуелни елементи
- За подобро разбирање на концептот

### 2. AI PROMPT ЗА MANIM:
```

Теорема: [ИМЕ НА ТЕОРЕМАТА]
Категорија: [КАТЕГОРИЈА]

ГЕНЕРИРАЈ MANIM КОД ЗА ВИЗУЕЛИЗАЦИЈА НА ДОКАЗОТ:

## ПРАВИЛА ЗА MANIM КОД:
class [TheoremName]ProofScene(Scene):
    def construct(self):
        # 1. Креирај основни елементи
        # 2. Анимирај чекори од доказот
        # 3. Покажи заклучок
        # 4. Додај текст објаснувања

## ОСНОВНИ ЕЛЕМЕНТИ:
- Triangle, Circle, Line, Dot со labels
- Tex/MathTex за формули, Text за објаснувања
- Write, FadeIn, Transform, Indicate за анимации

ГЕНЕРИРАЈ КОМПЛЕТЕН MANIM КОД ЗА ВИЗУЕЛИЗАЦИЈА НА ДОКАЗОТ!

### 3. ЕКСПЕРТСКИ MANIM СОВЕТИ:
- Користи `self.play()` за анимации
- Групирај елементи во VGroup
- Користи `always_redraw` за динамични елементи
- Додај `self.wait()` помеѓу чекори
- Користи `TransformMatchingTex` за трансформација на равенки
