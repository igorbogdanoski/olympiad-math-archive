# Безбедност при распоредување

Ова репо е **јавно**. Во него не се пишуваат лозинки, клучеви ниту содржина од `.env`.

## Порти

- Однадвор смеат да бидат отворени само **80 и 443** (и SSH на серверот).
- Postgres, Redis и API се објавуваат само на `127.0.0.1` (`"127.0.0.1:5432:5432"`). Запис без IP
  (`"5432:5432"`) Docker го врзува на 0.0.0.0 и при тоа го заобиколува заштитниот ѕид (ufw).
- Апликацијата ги бара базите по внатрешното име во мрежата `app_network` (`postgres:5432`, `redis:6379`).
- Пристап до база од свој компјутер — само преку SSH-тунел: `ssh -L 5432:127.0.0.1:5432 <корисник>@<сервер>`.

## Redis

- Redis секогаш со лозинка: `REDIS_PASSWORD` во `.env` (`openssl rand -hex 24`), а апликацијата го користи
  `REDIS_URL=redis://:${REDIS_PASSWORD}@redis:6379`. Без неа compose одбива да стартува.

## Тајни

- `.env` на серверот со права `600`. Пример со замени: `.env.production.example`.
- Пред комит: `git diff --cached` не смее да содржи вистински вредности за `*_PASSWORD`, `*_SECRET`, `*_KEY`.

## Зошто (27.10.2026)

Во продукција Redis беше на 0.0.0.0:6379 без лозинка, а Postgres на 0.0.0.0:5432. Однадвор Redis одговараше
на секоја команда и во него беа запишани туѓи клучеви. Поправено со горните правила; лозинките на базата
не биле во историјата на ова репо.
