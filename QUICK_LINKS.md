## 🔧 TROUBLESHOOTING

### Ако линк не работи:

1. **Провери дали серверот работи**:
   ```powershell
   Get-Process node
   ```

2. **Провери порт**:
   ```powershell
   netstat -ano | findstr "4321"
   ```

3. **Рестартирај сервер**:
   ```powershell
   cd C:\Users\pc4all\Documents\matholimpiad\olympiad-math-archive\web
   npm run dev
   ```

4. **Отвори во browser**:
   - Chrome: http://localhost:4321/
