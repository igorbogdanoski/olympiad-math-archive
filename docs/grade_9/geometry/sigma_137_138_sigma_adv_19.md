# Плоштина на правоаголен триаголник (p, q)

## Текст на задачата
Впишаната кружница во правоаголен триаголник ја допира хипотенузата во точка која ја дели на отсечки со должини $p$ и $q$. Докажи дека плоштината на триаголникот е $P = p \cdot q$.

## 📐 Скица / Конструкција


## 🧠 Анализа
Нека $r$ е радиусот на впишаната кружница. Изрази ги катетите преку $p, q, r$ користејќи го својството на тангентни отсечки од исто теме ($a=q+r, b=p+r$). Потоа искористи ја Питагоровата теорема или формулата за плоштина.

## 📝 Решение (СИНТЕТИЧКО)
Нека допирната точка на хипотенузата е $D$. Нека $BD=q$ и $AD=p$.
Нека $r$ е радиусот на впишаната кружница.

1. **Тангентни отсечки:**
   Од темето $C$ (прав агол), тангентните отсечки до кружницата формираат квадрат со страна $r$. Значи делот од катетите до допирните точки е $r$.
   Од темето $B$, тангентните отсечки се еднакви: $BD = q$, па и делот од катетата е $q$.
   Од темето $A$, тангентните отсечки се еднакви: $AD = p$, па и делот од катетата е $p$.

   Значи катетите се:
   $a = q + r$
   $b = p + r$
   Хипотенузата е $c = p + q$.

2. **Плоштина преку полупериметар:**
   Полупериметарот е $s = \frac{a+b+c}{2} = \frac{(q+r) + (p+r) + (p+q)}{2} = p+q+r$.
   Плоштината е $P = s \cdot r = (p+q+r)r = pr + qr + r^2$.

3. **Врска од Питагора:**
   $a^2 + b^2 = c^2$
   $(q+r)^2 + (p+r)^2 = (p+q)^2$
   $q^2 + 2qr + r^2 + p^2 + 2pr + r^2 = p^2 + 2pq + q^2$
   Поништуваме $p^2$ и $q^2$:
   $2qr + 2pr + 2r^2 = 2pq$
   Делиме со 2:
   $qr + pr + r^2 = pq$

4. **Заклучок:**
   Видовме дека $P = pr + qr + r^2$.
   Од Питагора добивме $pq = pr + qr + r^2$.
   Следи $P = pq$.

**Резултат:** Докажано.
