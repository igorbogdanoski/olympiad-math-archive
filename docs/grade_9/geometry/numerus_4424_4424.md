# Паралелограм и центар на впишана кружница

## Текст на задачата
Нека $k$ е опишаната кружница околу разностраниот остроаголен $\triangle ABC$. На неа $A'$ е средината на лакот $\widehat{BC}$ кој не ја содржи $A$, $B'$ е средината на $\widehat{CA}$ кој не ја содржи $B$ и $C'$ е средината на $\widehat{AB}$ кој ја содржи $C$. Ако $V$ е центарот на впишаната кружница во $\triangle ABC$, докажи дека $A'C'B'V$ е паралелограм.

## 📐 Скица / Конструкција


## 🧠 Анализа
Задачата се потпира на 'Лемата за трилист' (Trillium Theorem), која вели дека $A'V = A'C$. За да докажеме дека е паралелограм, доволно е да покажеме дека спротивните страни се еднакви ($A'V = B'C'$ и $B'V = A'C'$). Ова најлесно се прави преку пресметка на должини на кружни лаци.

## 📝 Решение (СИНТЕТИЧКО)
За да докажеме дека $A'C'B'V$ е паралелограм, ќе докажеме дека спротивните страни се еднакви: $A'V = B'C'$ и $B'V = A'C'$.

### Чекор 1: Лема за трилист (Trillium Theorem)
Прво ќе го докажеме познатото својство за центарот на впишана кружница $V$.
> **Лема:** Ако $A'$ е средина на лакот $BC$, тогаш $A'V = A'C$.

**Доказ на лемата:**
Означуваме агли $\angle A = 2\alpha, \angle B = 2\beta, \angle C = 2\gamma$.
1. $\angle A'CV = \angle A'CB + \angle BCV$. 
   - $\angle BCV = \gamma$ (бидејќи $CV$ е симетрала).
   - $\angle A'CB = \angle A'AB = \alpha$ (агли над ист лак $A'B$, а $AA'$ е симетрала).
   - Значи $\angle A'CV = \alpha + \gamma$.
2. $\angle A'VC$ е надворешен за $\triangle AVC$.
   - $\angle A'VC = \angle VAC + \angle VCA = \alpha + \gamma$.
3. Бидејќи $\angle A'CV = \angle A'VC$, триаголникот $\triangle A'VC$ е рамнокрак и **$A'V = A'C$**.

Аналогно важи и **$B'V = B'C$**.

### Чекор 2: Пресметка на лаците
Нека целата кружница има $360^\circ$. Лаците што одговараат на страните се:
- $\text{Arc } BC = 2\cdot(2\alpha) = 4\alpha$
- $\text{Arc } AC = 2\cdot(2\beta) = 4\beta$
- $\text{Arc } AB = 2\cdot(2\gamma) = 4\gamma$
*(Забелешка: Користиме ознаки каде аглите на триаголникот се $2\alpha, 2\beta, 2\gamma$ за полесно делење со 2).*

Позициите на точките:
- $A'$ е средина на $\text{Arc } BC \implies \text{Arc } A'C = 2\alpha$.
- $B'$ е средина на $\text{Arc } AC \implies \text{Arc } B'C = 2\beta$.
- $C'$ е средина на лакот $AB$ што го содржи $C$. Тој лак е збир на другите два: $\text{Arc } ACB = 4\alpha + 4\beta$. Значи $\text{Arc } AC' = 2\alpha + 2\beta$.

### Чекор 3: Споредување на тетивите
Треба да докажеме $A'V = B'C'$. Од Лемата знаеме $A'V = A'C$. Значи треба да докажеме $A'C = B'C'$.
Доволно е да покажеме дека лаците над овие тетиви се еднакви.

1. **Лакот за $A'C$:** Веќе пресметавме $\text{Arc } A'C = 2\alpha$.
2. **Лакот за $B'C'$:**
   Тој е разлика помеѓу $\text{Arc } AC'$ и $\text{Arc } AB'$.
   $$ \text{Arc } B'C' = \text{Arc } AC' - \text{Arc } AB' $$
   $$ \text{Arc } B'C' = (2\alpha + 2\beta) - 2\beta = 2\alpha $$

Бидејќи лаците се еднакви ($2\alpha$), и тетивите се еднакви:
$$ A'C = B'C' $$
Комбинирано со лемата ($A'V = A'C$), добиваме:
$$ \mathbf{A'V = B'C'} $$

### Чекор 4: Симетрија
Аналогно докажуваме за другата двојка.
- $\text{Arc } B'C = 2\beta$.
- $\text{Arc } A'C' = \text{Arc } BC' - \text{Arc } BA' = (2\alpha + 2\beta) - 2\alpha = 2\beta$.
- Значи $B'C = A'C'$.
- Од лемата $B'V = B'C$, па следи **$B'V = A'C'$**.

### Заклучок
Во четириаголникот $A'C'B'V$ спротивните страни се еднакви ($A'V=B'C'$ и $B'V=A'C'$), што значи дека тој е **паралелограм**.
