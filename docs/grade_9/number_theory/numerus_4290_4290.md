# Деливост со 30

## Текст на задачата
Нека $a,b,c$ се природни броеви такви што $5a+2b=3c$. Докажи дека $30 \mid (a+b)(b+c)(c+a)$.

## 🧠 Анализа (Клучна идеја)
Треба да докажеш деливост со 2, 3 и 5. Користи го условот $5a+2b=3c$ по соодветниот модул.

## 📝 Решение
Треба да докажеме дека $P = (a+b)(b+c)(c+a)$ е делив со 2, 3 и 5.

1.  **Деливост со 2:**
    Услов: $5a+2b=3c$. Модул 2: $a + 0 \equiv c \pmod 2 \implies a \equiv c$.
    Ако $a, c$ се со иста парност, тогаш $a+c$ е парен.
    Значи $2 \mid (c+a)$, па $2 \mid P$.

2.  **Деливост со 3:**
    Услов: $5a+2b=3c$. Модул 3: $2a + 2b \equiv 0 \pmod 3 \implies 2(a+b) \equiv 0 \pmod 3$.
    Бидејќи НЗД(2,3)=1, следи $a+b \equiv 0 \pmod 3$.
    Значи $3 \mid (a+b)$, па $3 \mid P$.

3.  **Деливост со 5:**
    Услов: $5a+2b=3c$. Модул 5: $2b \equiv 3c \pmod 5$.
    Множиме со 3 (инверз на 2 mod 5): $6b \equiv 9c \implies b \equiv 4c \equiv -c \pmod 5$.
    Значи $b+c \equiv 0 \pmod 5$.
    Значи $5 \mid (b+c)$, па $5 \mid P$.

Бидејќи 2, 3, 5 се заемно прости, $2 \cdot 3 \cdot 5 = 30 \mid P$.
