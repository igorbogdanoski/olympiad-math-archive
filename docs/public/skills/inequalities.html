Inequalities

Што е оваа вештина?

Inequalities (нееднаквости) се вештина за споредување вредности и за наоѓање максимум или минимум под дадени услови.

Наместо точна вредност, целта е:

„Колку големо / мало МОЖЕ да биде?“

Зошто е олимписка?

Нееднаквостите се сржта на олимписката алгебра. Тие: - учат оптимизација - развиваат чувство за екстреми - ја користат симетријата и границите

Сврзани теореми

  • AM-GM нееднаквост
  • Cauchy-Schwarz нееднаквост
  • Начин на pigeonhole

Примени во задачи

🟢 Основни техники

  • AM-GM нееднаквост: $(a+b)/2 ≥ √(ab)$ за позитивни броеви
  • Cauchy-Schwarz: $(a₁b₁ + a₂b₂)² ≤ (a₁² + a₂²)(b₁² + b₂²)
  • Триаголна нееднаквост: |a + b| ≤ |a| + |b|

🟡 Средно напредни техники

  • Симетрично парирање: f(x) + f(1-x) = константа
  • Параметарски нееднаквости: Најди опсег на параметар
  • Нееднаквости со две променливи: f(x,y) ≤ g(x,y)

Поврзани задачи

Основни задачи

  • Нееднаквост со параметар
  • Минимум на симетричен израз

Напредни задачи

  • Нееднаквост со комплексни броеви
  • Телескопски суми со корени

Предуслови

  • Algebraic transformation
  • Boundary cases
  • Symmetry (основно)

Типични грешки

  • Механичка примена на формули (AM–GM без смисла)
  • Игнорирање гранични случаи
  • Заборавање на условите (ненегативност, збир = константа)

Мини-вежби

🟢 Intro

Спореди: [ x^2 + 1 \quad \text{и} \quad 2x ] за реални (x).

🟡 Core

Најди го максимумот на: [ xy \quad \text{ако} \quad x+y=10. ]

🔴 Advanced

Докажи нееднаквост со симетрија и случај (x=y).

Туторски насоки

  • Прашај: „Кога се еднакви?“
  • Провери секогаш граници (0, максимум)
  • Барај објаснување, не само резултат
