# Систем со корени

## 📝 Текст на задачата
Одреди ги сите позитивни реални броеви $a, b, c$ за кои што важи:

$$ 2\sqrt{a} + 3\sqrt{b} + 6\sqrt{c} = a + b + c = 49 $$

## 🧠 Анализа (Клучна идеја)
Имаме две равенки. Ако ги одземеме, добиваме една равенка со три непознати еднаква на 0. Ова обично сугерира дека изразот може да се запише како збир на квадрати. Префрлете сè на една страна: $a - 2\sqrt{a} + b - 3\sqrt{b} + c - 6\sqrt{c} + \dots = 0$.

## 💡 Решение

??? tip "Чекор 1: Формирање на разликата"
    Дадено е:
    1. $a + b + c = 49$
    2. $2\sqrt{a} + 3\sqrt{b} + 6\sqrt{c} = 49$
    
    Одземаме (2) од (1):
    
    $$ (a + b + c) - (2\sqrt{a} + 3\sqrt{b} + 6\sqrt{c}) = 49 - 49 $$
    
    $$ a - 2\sqrt{a} + b - 3\sqrt{b} + c - 6\sqrt{c} = 0 $$

??? tip "Чекор 2: Комплетирање на квадрати"
    За да формираме полни квадрати од типот $(\sqrt{x} - k)^2 = x - 2k\sqrt{x} + k^2$, ни недостасуваат слободните членови.
    
    *   За $a - 2\sqrt{a}$, треба $+1$. (бидејќи $2k=2 \implies k=1$)
    *   За $b - 3\sqrt{b}$, треба $+(1.5)^2 = 2.25$. (бидејќи $2k=3 \implies k=1.5$)
    *   За $c - 6\sqrt{c}$, треба $+9$. (бидејќи $2k=6 \implies k=3$)
    
    Но, чекајте! Збирот на константите треба да биде 0? Не, ние треба да ја „растуриме“ 49-ката од десната страна? 
    Ајде да видиме: $a+b+c = 49$. 
    Заменуваме во равенката:
    
    $$ (a - 2\sqrt{a} + 1) + (b - 3\sqrt{b} + \frac{9}{4}) + (c - 6\sqrt{c} + 9) = 1 + 2.25 + 9 = 12.25 $$
    
    Ова не е 0. Дали има грешка во преписот? 
    Ајде да го провериме решението од сликата. Таму пишува: $a=4, b=9, c=36$. 
    Проверка: $4+9+36=49$. $2(2)+3(3)+6(6) = 4+9+36=49$. Точно.
    Како се добива? 
    Аха! Равенката е $a - 4\sqrt{a} + 4 + b - 6\sqrt{b} + 9 + c - 12\sqrt{c} + 36 = 0$?
    Тоа би значело дека почетната равенка е $2\sqrt{a} + 3\sqrt{b} + 6\sqrt{c} = \frac{1}{2}(a+b+c)$? 
    Не, текстот вели $2\sqrt{a}... = 49$. 
    
    Да се вратиме на решението од сликата (Image 8): 
    Таму пишува: $a - 4\sqrt{a} + 4 + b - 6\sqrt{b} + 9 + c - 12\sqrt{c} + 36 = 0$.
    Ова значи дека равенката што ја решавале е: $4\sqrt{a} + 6\sqrt{b} + 12\sqrt{c} = a+b+c+49$. 
    Или можеби текстот на задачата е: $2\sqrt{a} + 3\sqrt{b} + 6\sqrt{c} = \frac{a+b+c+49}{2}$?
    
    Да ја погледнеме сликата 7 (Problem 1A) повторно.
    Текстот е: $2\sqrt{a} + 3\sqrt{b} + 6\sqrt{c} = a+b+c = 49$.
    Решението (Image 7 bottom) вели: $a+b+c - 2(2\sqrt{a} + 3\sqrt{b} + 6\sqrt{c}) = 49 - 2(49) = -49$.
    Аха! Значи ја множиме равенката со корените со 2!
    
    **Коригиран Чекор 1:**
    Имаме $2\sqrt{a} + 3\sqrt{b} + 6\sqrt{c} = 49$. Множиме со 2:
    
    $$ 4\sqrt{a} + 6\sqrt{b} + 12\sqrt{c} = 98 $$
    
    Имаме $a+b+c = 49$.
    Одземаме:
    
    $$ (a+b+c) - (4\sqrt{a} + 6\sqrt{b} + 12\sqrt{c}) = 49 - 98 = -49 $$
    
    $$ a - 4\sqrt{a} + b - 6\sqrt{b} + c - 12\sqrt{c} + 49 = 0 $$

??? tip "Чекор 2: Распаѓање на 49"
    Ни требаат константи за полни квадрати:
    
    *   $(\sqrt{a}-2)^2 \to 4$
    *   $(\sqrt{b}-3)^2 \to 9$
    *   $(\sqrt{c}-6)^2 \to 36$
    
    Збир: $4+9+36 = 49$. Совршено!
    
    $$ (a - 4\sqrt{a} + 4) + (b - 6\sqrt{b} + 9) + (c - 12\sqrt{c} + 36) = 0 $$
    
    $$ (\sqrt{a}-2)^2 + (\sqrt{b}-3)^2 + (\sqrt{c}-6)^2 = 0 $$

??? tip "Чекор 3: Решенија"
    Збир на квадрати е 0 само ако секој е 0.
    
    *   $\sqrt{a}=2 \implies a=4$
    *   $\sqrt{b}=3 \implies b=9$
    *   $\sqrt{c}=6 \implies c=36$
