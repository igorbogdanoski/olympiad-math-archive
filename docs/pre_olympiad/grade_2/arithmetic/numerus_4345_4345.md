# Непарни броеви до 10

## Текст на задачата
Кој е најмалиот, а кој најголемиот непарен број во првата десетка? Колку изнесува нивниот збир?

## 🧠 Анализа (Клучна идеја)
Наброј ги: 1, 3, 5, 7, 9.

## 📝 Решение
Непарни броеви: $1, 3, 5, 7, 9$.
- Најмал: **1**
- Најголем: **9**
- Збир: $1 + 9 = 10$.
