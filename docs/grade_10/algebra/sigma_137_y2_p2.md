# Ограничени квадратни функции

# Текст на задачата
Најди ги сите реални броеви $$a$$ и $$b$$ такви што за секој $$x \in [-1, 1]$$ важи неравенството:

$$|2x^2 + ax + b| \le 1$$

# 💡 Помош (Hints)
<details>
<summary>Кликни за мала помош</summary>

1. Дефинирај ја функцијата $$f(x) = 2x^2 + ax + b$$. Условот вели дека нејзиниот график мора да биде „заробен“ помеѓу правите $$y = -1$$ и $$y = 1$$ за сите вредности на $$x$$ во интервалот $$[-1, 1]$$.

2. Што се случува во критичните точки на интервалот? Пробај да ги замениш вредностите за $$x = -1$$, $$x = 0$$ и $$x = 1$$.

3. Искористи ги добиените неравенства за да ги ограничиш вредностите на параметрите $$a$$ и $$b$$. Дали постои само една единствена можност?

</details>

# Решение

## 🧠 Експертска Анализа (Интуиција)
Оваа задача нè воведува во светот на **екстремалните својства на полиномите**. Замислете дека имате парабола чиј водечки коефициент е фиксиран ($$2$$). Тој коефициент ја одредува „ширината“ на параболата. Прашањето е: како да ја поместиме таа парабола лево-десно (преку $$a$$) и горе-долу (преку $$b$$) така што таа воопшто да не излезе од еден мал правоаголник со ширина од $$-1$$ до $$1$$ и висина од $$-1$$ до $$1$$?,

**Тригерот** овде е условот „за секој $$x$$“. Тоа е многу силен услов. Ако нешто важи за секој $$x$$, мора да важи и за трите клучни точки кои ја дефинираат параболата во овој интервал: крајните точки и средината. Ако успееме да ја „заглавиме“ параболата во овие точки, веројатно ќе го најдеме решението. Оваа парабола е всушност познатиот **Чебишев полином** од втор степен, кој е дизајниран токму да има најмало можно отстапување од нулата.

## 📐 Детално Решение

<details>
<summary>Чекор 1: Поставување на системот неравенки во клучните точки</summary>

Нека е дадена функцијата $$f(x) = 2x^2 + ax + b$$. Од условот на задачата, знаеме дека $$-1 \le f(x) \le 1$$ за секој $$x \in [-1, 1]$$.

Да ги разгледаме вредностите во точките $$-1$$, $$0$$ и $$1$$:

За $$x = 0$$:
$$-1 \le f(0) \le 1 \Rightarrow -1 \le b \le 1$$

За $$x = 1$$:
$$-1 \le f(1) \le 1 \Rightarrow -1 \le 2 + a + b \le 1 \Rightarrow -3 \le a + b \le -1$$

За $$x = -1$$:
$$-1 \le f(-1) \le 1 \Rightarrow -1 \le 2 - a + b \le 1 \Rightarrow -3 \le -a + b \le -1$$

</details>

<details>
<summary>Чекор 2: Определување на вредноста за b</summary>

Од претходниот чекор ги издвојуваме двете клучни десни неравенства:

$$a + b \le -1$$

$$-a + b \le -1$$

Ако ги собереме овие две неравенства, добиваме:

$$(a + b) + (-a + b) \le -1 + (-1)$$

$$2b \le -2 \Rightarrow b \le -1$$

Меѓутоа, од вредноста во точката $$x = 0$$, веќе знаеме дека $$b \ge -1$$.
Единствениот реален број кој ги задоволува условите $$b \le -1$$ и $$b \ge -1$$ е:

$$b = -1$$

</details>

<details>
<summary>Чекор 3: Определување на вредноста за a и проверка</summary>

Сега ја заменуваме вредноста $$b = -1$$ назад во неравенствата:

Од $$a + b \le -1$$ добиваме $$a - 1 \le -1 \Rightarrow a \le 0$$.

Од $$-a + b \le -1$$ добиваме $$-a - 1 \le -1 \Rightarrow -a \le 0 \Rightarrow a \ge 0$$.

Бидејќи $$a \le 0$$ и $$a \ge 0$$, мора да важи:

$$a = 0$$

Сега треба да провериме дали параболата $$f(x) = 2x^2 - 1$$ го задоволува условот за сите $$x \in [-1, 1]$$. Бидејќи за $$x^2 \in$$, вредноста на $$2x^2$$ е во интервалот $$$$, следи дека $$2x^2 - 1$$ се движи во интервалот $$[-1, 1]$$. Со тоа, решението е потврдено.

</details>

**Краен одговор:** $$\boxed{a = 0, b = -1}$$

## 👨‍🏫 Менторски Белешки
1. **Златен Совет:** Овој тип задачи често се решаваат со разгледување на **екстремните точки** (endpoints) на дефиниционот домен. Ако полиномот е ограничен во целиот интервал, тој мора да биде ограничен и во неговите краишта.
2. **Чести Грешки:** Учениците често забораваат да проверат дали најдените вредности на $$a$$ и $$b$$ навистина го задоволуваат условот за **секој** $$x$$. Понекогаш точките на краиштата даваат кандидати кои во средината на интервалот „излегуваат“ од границите.
3. **Зошто ова е важно:** Оваа задача е всушност специјален случај на теоремата за Чебишеви полиноми. Тие се полиноми кои најмалку отстапуваат од нулата на интервалот $$[-1, 1]$$. Во нашиот случај, тоа е полиномот $$T_2(x) = 2x^2 - 1$$.
