# Решавање рационална неравенка со воведување смена

# Текст на задачата
Во множеството на реални броеви реши ја неравенката:

$$x^2 + x + \frac{3}{x^2 + x + 1} \le 3$$

# 💡 Помош (Hints)
<details>
<summary>Кликни за мала помош</summary>

1. Наместо да множиш сè со именителот, погледни ја структурата на изразот. Дали се повторува некој блок од променливи?

$$x^2 + x$$

2. Избери смена која ќе го направи именителот наједноставен. Што ако целиот именител го означиме со нова променлива $t$?

$$t = x^2 + x + 1$$

3. Внимавај на вредностите кои може да ги прими $t$. Бидејќи $x^2 + x + 1 = (x + 1/2)^2 + 3/4$, заклучи го опсегот на $t$.

</details>

# Решение
## 🧠 Експертска Анализа (Интуиција)
Кога решаваме рационални неравенки од овој тип, „грубата сила“ (сведување на заеднички именител без претходна анализа) често води до полиноми од четврти степен кои се тешки за факторизација. **Тригерот** овде е очигледната повторливост на изразот $x^2 + x$.

Зошто воведуваме смена? Смената е како лупа која ни овозможува да ја видиме основната структура на проблемот. Ако го означиме именителот со $t$, неравенката од рационална со $x^2$ се трансформира во едноставна квадратна неравенка по $t$. Искуството ни вели дека секогаш е подобро да работиме со израз кој е строго позитивен ($x^2 + x + 1 > 0$), бидејќи тоа го олеснува множењето без промена на знакот на неравенството.

## 📐 Детално Решение

<details>
<summary>Чекор 1: Воведување смена и анализа на доменот</summary>

Да го анализираме изразот $x^2 + x + 1$. Со дополнување до полн квадрат добиваме:

$$x^2 + x + 1 = (x + \frac{1}{2})^2 + \frac{3}{4}$$

Бидејќи $(x + 1/2)^2 \ge 0$, следува дека $x^2 + x + 1 \ge 3/4$ за секој реален број $x$. Ова значи дека изразот е секогаш позитивен и неравенката е дефинирана за секој $x \in \mathbb{R}$. Воведуваме смена:

$$t = x^2 + x + 1, \quad t \in [\frac{3}{4}, \infty)$$

Од тука, $x^2 + x = t - 1$.

</details>

<details>
<summary>Чекор 2: Решавање на неравенката по t</summary>

Ја заменуваме смената во почетната неравенка:

$$(t - 1) + \frac{3}{t} \le 3$$

Префрламе сè на левата страна:

$$t - 4 + \frac{3}{t} \le 0$$

Бидејќи $t \ge 3/4 > 0$, можеме слободно да помножиме со $t$ без да го менуваме знакот на неравенството:

$$t^2 - 4t + 3 \le 0$$

Корените на квадратниот трином $t^2 - 4t + 3 = 0$ се $t_1 = 1$ и $t_2 = 3$. Решението на неравенката по $t$ е:

$$t \in [1, 3]$$

Овој интервал е во согласност со нашиот услов $t \ge 3/4$.

</details>

<details>
<summary>Чекор 3: Враќање на смената и финално решение</summary>

Сега ги решаваме двете неравенки за $x$:

1. Прв дел ($t \ge 1$):
$$x^2 + x + 1 \ge 1 \implies x^2 + x \ge 0 \implies x(x + 1) \ge 0$$
Решението е $x \in (-\infty, -1] \cup [0, \infty)$.

2. Втор дел ($t \le 3$):
$$x^2 + x + 1 \le 3 \implies x^2 + x - 2 \le 0 \implies (x + 2)(x - 1) \le 0$$
Корените се $-2$ и $1$, па решението е $x \in [-2, 1]$.

Конечното решение е пресекот на овие две множества:

$$x \in ( (-\infty, -1] \cup [0, \infty) ) \cap [-2, 1]$$

Пресекот на $(-\infty, -1]$ и $[-2, 1]$ е $[-2, -1]$.
Пресекот на $[0, \infty)$ и $[-2, 1]$ е $[0, 1]$.

</details>

**Краен одговор:** $\boxed{x \in [-2, -1] \cup [0, 1]}$

## 👨‍🏫 Менторски Белешки
1. **Златен Совет:** При избор на смена, секогаш стреми се кон онаа што го елиминира „најопасното“ место во задачата — именителот. Да го означевме само $x^2 + x = u$, равенката ќе беше $u + 3/(u+1) \le 3$, што е исто, но малку поподно за грешки при средувањето.
2. **Чести Грешки:** Заборавање на условот $t > 0$. Кај рационални неравенки, ако именителот може да биде негативен, мора да се разгледуваат два случаи при множење.
3. **Зошто ова е важно:** Оваа техника на „препознавање обрасци“ е клучна за решавање на равенки од повисок степен на натпреварите од републички и меѓународен ранг.
