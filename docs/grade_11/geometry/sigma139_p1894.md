# Текст на задачата
Нека $ABCD$ е квадрат. Отсечката $AB$ е поделена внатрешно со точка $H$ така што $\overline{AB} \cdot \overline{BH} = \overline{AH}^2$. Нека $E$ е средишна точка на отсечката $AD$ и $X$ е средишна точка на отсечката $AH$. Нека $Y$ е точка од отсечката $EB$ така што $XY$ е нормална на $EB$. Докажи дека $\overline{XY} = \overline{XH}$.

# Решение
## Стратегија
Условот $\overline{AB} \cdot \overline{BH} = \overline{AH}^2$ е дефиницијата за **златен пресек**. Точката $H$ ја дели отсечката $AB$ во златен пресек.
Ова значи дека ако страната на квадратот е $a$, тогаш $AH = \frac{\sqrt{5}-1}{2}a$.
Задачата бара да докажеме еднаквост на отсечки $XY = XH$. Ова сугерира дека $X$ е центар на кружница што минува низ $Y$ и $H$, или дека $\triangle XYH$ е рамнокрак.
Бидејќи $XY \perp EB$, триаголникот $\triangle XYB$ е правоаголен.
Можеме да користиме аналитичка геометрија (координати) бидејќи имаме квадрат и многу средишни точки, што ги прави пресметките едноставни.
Алтернативно, можеме да користиме сличност на триаголници.

## 📐 Детално Решение

<details>
<summary>Чекор 1: Поставување на координатен систем</summary>

Нека $A(0, 2a)$. Тогаш $B(2a, 2a)$, $C(2a, 0)$, $D(0, 0)$.
(Избираме $2a$ за да избегнеме дропки со средишните точки).
Страната на квадратот е $2a$.

</details>

<details>
<summary>Чекор 2: Координати на точките</summary>

*   $E$ е средина на $AD$. $A(0, 2a), D(0, 0) \implies E(0, a)$.
*   $H$ ја дели $AB$ во златен пресек.
    Условот е $AB \cdot BH = AH^2$.
    Нека $AH = x$. Тогаш $BH = 2a - x$.
    $2a(2a - x) = x^2 \implies x^2 + 2ax - 4a^2 = 0$.
    $x = \frac{-2a + \sqrt{4a^2 + 16a^2}}{2} = a(\sqrt{5} - 1)$.
    Значи $AH = a(\sqrt{5} - 1)$.
    Координатите на $H$ се $(a(\sqrt{5}-1), 2a)$.
*   $X$ е средина на $AH$.
    $x_X = \frac{0 + a(\sqrt{5}-1)}{2} = \frac{a(\sqrt{5}-1)}{2}$.
    $y_X = 2a$.
    Значи $X\left( \frac{a(\sqrt{5}-1)}{2}, 2a \right)$.

</details>

<details>
<summary>Чекор 3: Равенка на правата $EB$</summary>

Точките се $E(0, a)$ и $B(2a, 2a)$.
Коефициентот на правец е $k_{EB} = \frac{2a - a}{2a - 0} = \frac{a}{2a} = \frac{1}{2}$.
Равенката е $y - a = \frac{1}{2}(x - 0) \implies y = \frac{1}{2}x + a$.

</details>

<details>
<summary>Чекор 4: Равенка на правата $XY$</summary>

Правата $XY$ е нормална на $EB$, па нејзиниот коефициент е $k_{XY} = -2$.
Минува низ $X\left( \frac{a(\sqrt{5}-1)}{2}, 2a \right)$.
Равенката е:
$y - 2a = -2\left( x - \frac{a(\sqrt{5}-1)}{2} \right)$
$y = -2x + a(\sqrt{5}-1) + 2a = -2x + a(\sqrt{5}+1)$.

</details>

<details>
<summary>Чекор 5: Координати на точката $Y$</summary>

$Y$ е пресек на $EB$ и $XY$.
$\frac{1}{2}x + a = -2x + a(\sqrt{5}+1)$
$\frac{5}{2}x = a\sqrt{5}$
$x = \frac{2a\sqrt{5}}{5} = \frac{2a}{\sqrt{5}}$.
$y = \frac{1}{2}\left( \frac{2a}{\sqrt{5}} \right) + a = \frac{a}{\sqrt{5}} + a = a\left( 1 + \frac{1}{\sqrt{5}} \right)$.

</details>

<details>
<summary>Чекор 6: Пресметка на растојанијата</summary>

Треба да докажеме $XY^2 = XH^2$.
*   Растојание $XH$:
    $X$ е средина на $AH$, па $XH = \frac{AH}{2} = \frac{a(\sqrt{5}-1)}{2}$.
    $XH^2 = \frac{a^2(5 - 2\sqrt{5} + 1)}{4} = \frac{a^2(6 - 2\sqrt{5})}{4} = \frac{a^2(3 - \sqrt{5})}{2}$.

*   Растојание $XY$:
    $X\left( \frac{a(\sqrt{5}-1)}{2}, 2a \right)$, $Y\left( \frac{2a}{\sqrt{5}}, a\left(1+\frac{1}{\sqrt{5}}\right) \right)$.
    $x_X - x_Y = \frac{a\sqrt{5}-a}{2} - \frac{2a}{\sqrt{5}} = \frac{5a - a\sqrt{5} - 4a}{2\sqrt{5}} = \frac{a - a\sqrt{5}}{2\sqrt{5}}$.
    $y_X - y_Y = 2a - a - \frac{a}{\sqrt{5}} = a - \frac{a}{\sqrt{5}} = \frac{a\sqrt{5}-a}{\sqrt{5}}$.

    $XY^2 = \left( \frac{a(1-\sqrt{5})}{2\sqrt{5}} \right)^2 + \left( \frac{a(\sqrt{5}-1)}{\sqrt{5}} \right)^2$
    $XY^2 = \frac{a^2(1 - 2\sqrt{5} + 5)}{20} + \frac{a^2(5 - 2\sqrt{5} + 1)}{5}$
    $XY^2 = \frac{a^2(6 - 2\sqrt{5})}{20} + \frac{4a^2(6 - 2\sqrt{5})}{20}$
    $XY^2 = \frac{5a^2(6 - 2\sqrt{5})}{20} = \frac{a^2(6 - 2\sqrt{5})}{4} = \frac{a^2(3 - \sqrt{5})}{2}$.

**Заклучок:**
Добивме дека $XH^2 = \frac{a^2(3 - \sqrt{5})}{2}$ и $XY^2 = \frac{a^2(3 - \sqrt{5})}{2}$.
Следи дека $XY = XH$.

# Pedagogical Notes
1.  **Основна идеја:** Златниот пресек ($\phi = \frac{\sqrt{5}-1}{2}$) има многу интересни алгебарски својства, како $\phi^2 = 1 - \phi$. Користењето на координати е често најсигурниот пат кога имаме „тешки“ односи како златниот пресек, бидејќи алгебрата сама се средува.
2.  **Совет од Олимпиец:** Не плашете се од ирационални броеви во координатите. Ако правилно ги поставите (на пр. $A$ во координатен почеток или на оска), изразите често се кратат. Овде, клучно беше да се избере страната на квадратот како $2a$ за да се избегнат половинки кај средишните точки.
3.  **Алтернатива:** Задачата може да се реши и со сличност. $\triangle ABE \sim \triangle X'YE'$ (каде $X', E'$ се проекции), но тоа бара многу повеќе интуиција за да се најдат вистинските триаголници.

```python
from manim import *

class GoldenRatioSquare(Scene):
    def construct(self):
        self.camera.background_color = WHITE
        
        # Scale factor
        s = 3
        
        # Points
        A = UP * s + LEFT * s
        B = UP * s + RIGHT * s
        C = DOWN * s + RIGHT * s
        D = DOWN * s + LEFT * s
        
        # Square
        square = Polygon(A, B, C, D, color=BLACK)
        
        # Golden Ratio Point H
        # AH = AB * (sqrt(5)-1)/2
        # AB length = 2*s
        # AH len = 2*s * 0.618...
        phi = (np.sqrt(5) - 1) / 2
        H = A + RIGHT * (2 * s * phi)
        
        # Midpoints
        E = (A + D) / 2
        X = (A + H) / 2
        
        # Line EB
        line_EB = Line(E, B, color=BLUE)
        
        # Point Y (projection of X onto EB)
        # Vector EB
        vec_EB = B - E
        # Vector EX
        vec_EX = X - E
        # Projection scalar
        t = np.dot(vec_EX, vec_EB) / np.dot(vec_EB, vec_EB)
        Y = E + t * vec_EB
        
        line_XY = Line(X, Y, color=RED)
        line_XH = Line(X, H, color=GREEN)
        
        # Labels
        labels = VGroup(
            MathTex("A").next_to(A, UL),
            MathTex("B").next_to(B, UR),
            MathTex("C").next_to(C, DR),
            MathTex("D").next_to(D, DL),
            MathTex("E").next_to(E, LEFT),
            MathTex("H").next_to(H, UP),
            MathTex("X").next_to(X, UP),
            MathTex("Y").next_to(Y, DOWN)
        ).set_color(BLACK)
        
        # Right angle
        ra = RightAngle(line_XY, line_EB, length=0.2, color=RED)
        
        # Animation
        self.play(Create(square))
        self.play(Write(labels))
        self.play(Create(line_EB))
        self.play(Create(Dot(H, color=BLACK)), Create(Dot(X, color=BLACK)), Create(Dot(E, color=BLACK)))
        self.play(Create(line_XY), Create(ra))
        self.play(Create(line_XH))
        
        # Show equality
        self.play(Indicate(line_XY), Indicate(line_XH))
        
        eq_text = MathTex(r"XY = XH", color=BLACK).to_edge(DOWN)
        self.play(Write(eq_text))
        
        self.wait(2)

</details>
