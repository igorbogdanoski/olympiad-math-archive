## 🚀 Како да објавите на Vercel:

### Чекор 1: Подготовка на Git
```bash
cd c:/Users/pc4all/Documents/matholimpiad/olympiad-math-archive
git add .
git commit -m "feat: Enhanced theorems and skills with improved connectivity"
git push origin main
```

### Чекор 2: Поврзување со Vercel
1. Одете на [vercel.com](https://vercel.com)
2. Најавете се со GitHub
3. Кликнете **"Add New"** → **"Project"**
4. Изберете го репозиториумот `olympiad-math-archive`
5. **ВАЖНО:** Во "Root Directory" внесете `web`
6. Кликнете **"Deploy"**

### Чекор 3: Конфигурација
Vercel автоматски ќе го препознае Astro и ќе го конфигурира:
- ✅ Static генерација
- ✅ Automatic deployments при секој push
- ✅ SSL сертификати
- ✅ CDN оптимизација

## 🎯 Како да додавате докази за теореми:

### Опција 1: AI Генерирани Докази
```bash
# 1. Копирај го prompt-от од theorem_proof_workflow.md
# 2. Добиј доказ од AI (ChatGPT/Claude)
# 3. Зачувај го во tools/generated_proofs/[theorem_name]_proof.md
# 4. Интегрирај со:
python tools/integrate_proof.py [theorem_name] [proof_file].md
```

### Опција 2: Ручно Додавање
1. Отвори `web/src/data/theorems/[theorem_name].md`
2. Додај `## 📝 Доказ ([метод])` секција
3. Додај чекори со LaTeX формули
